Um [modelo](./Model.md) dentro de um [harness](./Harness.md), com [ferramentas](./Tool.md), um [prompt de sistema](./System%20prompt.md) e uma [janela de contexto](./Context%20window.md), que troca [turnos](./Turn.md) com um usuário. _O Claude Code é um agente. O Cursor é um agente. O Claude.ai é um agente._ O agente é com o que você de fato conversa — é o modelo em movimento, configurado para um propósito.

Diferente da maioria dos termos deste dicionário, "agente" não nomeia uma peça mecânica. O modelo é um arquivo de [parâmetros](./Parameters.md); o harness é software que você pode apontar. O agente não é nem um nem outro — é a unidade com quem você fala. As pessoas antropomorfizam [IA](./AI.md) o tempo todo, e o agente é a unidade antropomorfizada: a coisa a quem você delega, a coisa que lê sua mensagem e responde, o "ele" em "ele quebrou o build de novo". Quando você diz que o agente fez algo, quer dizer que o modelo mais o harness fizeram, mas está tratando a combinação como um ator só.

A ideia é mais antiga que esta onda de IA. Agentes de software — programas a que você delega um objetivo e que agem em seu nome — existem como conceito há tanto tempo quanto a própria IA.

_Evite:_ "a IA", "o bot" (vagos demais — escondem se você quer dizer os parâmetros ou a coisa com harness).

_Uso:_

"Qual agente você está usando para a migração?"

"Claude Code local, Cursor para a parte de UI — mesmo modelo por baixo, harnesses diferentes."
