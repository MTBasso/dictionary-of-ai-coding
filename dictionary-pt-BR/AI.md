Um rótulo móvel, não uma tecnologia. "IA" não nomeia uma coisa fixa como [modelo](./Model.md) ou [token](./Token.md) nomeiam — ela aponta para aquilo que os computadores acabaram de passar a fazer de forma impressionante. Hoje aponta para modelos de linguagem grandes. Já apontou para coisas bem diferentes:

| Época        | O que "IA" significava                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| Anos 1950    | Raciocínio simbólico — provadores de teoremas, programas de damas.                                     |
| Anos 1960–70 | Programas simbólicos baseados em regras — ELIZA, SHRDLU.                                               |
| Anos 1980    | Sistemas especialistas — milhares de regras se-então escritas à mão codificando conhecimento humano.   |
| Anos 1990    | Busca em árvore de jogo — Deep Blue vencendo Kasparov (1997). Os pesquisadores evitavam a palavra "IA" |
| Anos 2000    | Aprendizado de máquina estatístico — filtros de spam, recomendadores. Vendido como "machine learning"  |
| Anos 2010    | Aprendizado profundo — reconhecimento de imagens (AlexNet, 2012), AlphaGo (2016).                      |
| Anos 2020    | Modelos de linguagem grandes — o ChatGPT (2022) fez "IA" significar chatbots                           |

O ponteiro se move por um mecanismo conhecido, às vezes chamado de efeito IA: quando uma técnica passa a funcionar de forma confiável, ela é renomeada — é "só" busca, "só" estatística — e "IA" desliza para o próximo problema não resolvido. A observação é antiga. Bertram Raphael colocou assim em 1971: "IA é um nome coletivo para problemas que ainda não sabemos resolver direito por computador." A versão de Larry Tesler, de por volta de 1979: "Inteligência é tudo aquilo que as máquinas ainda não fizeram."

É por isso que conversas sobre IA tantas vezes passam uma pela outra. Uma afirmação como "IA não sabe raciocinar" ou "IA é hype" carrega uma data escondida — ela pode ser sobre sistemas especialistas, sobre classificadores de imagem dos anos 2010 ou sobre o LLM do mês passado, e cada referência sustenta uma conclusão diferente. Quando uma discussão sobre IA trava, a saída costuma ser trocar a palavra pelo termo preciso que se quer dizer: o modelo, o [harness](./Harness.md), o [agente](./Agent.md), o [contexto](./Context.md) que ele recebeu.

_Evite:_ "IA" em qualquer afirmação técnica — nomeie a parte de que você está falando. "Programação com IA" como rótulo da prática está bem; "a IA está alucinando" não está.

_Uso:_

"A CTO quer saber se dá para IA cuidar da fila de triagem."

"Traduza isso antes de estimar — ela quer dizer um LLM dentro de um harness com acesso ao sistema de tickets. 'IA' sozinho não é uma especificação."
